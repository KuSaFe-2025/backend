# KuSaFe Backend
## Лучшая бесплатная платформа для проведения викторин

KuSaFe - это бесплатная платформа для проведения онлайн викторин

- Поддержка динамического создания викторин
- Настраиваемый таймер
- ⭐Наличие доски лидеров⭐

## Главные функции

- Создание викторин, добавление, удаление, редактирование вопросов и опций
- Перемешивание вариантов ответа при новом открытии викторины
- Настроиваемый таймер для каждого отдельного вопроса
- Доска лидеров по времени, которое пользователь потратил на прохождение викторины
- Поддерка выбора цветовой палитры для карточки викторины, настройка названия, описания
- Воодушевляющие сообщения под каждым вопросом
- Система очков (разные вопросы дают разное количество очков)

## Технологии

Я использовал несколько технологий для бекэнда:

- ASP.NET Core в качестве основного фреймворка для HTTP взаимодействий
- ASP.NET Identity для отслеживания ролей пользователей (админ / юзер)
- EntityFramework Core в качестве ORM для PostgreSQL
- JWT токены как формат авторизации и аутентификации: access и refresh токены, реализация подписи стандартными средствами ASP.NET Core

## Запуск

Скомпилируйте:
```
dotnet build
```

После чего запустите:
```
dotnet KaSaFeBackend.dll
```
